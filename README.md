# Simple Interest Calculator

## Project Description

The Simple Interest Calculator is a simple Bash-based calculator that computes simple interest based on the principal amount, rate of interest, and time period provided by the user.

## Formula

The simple interest is calculated using the formula:

**Simple Interest = (Principal × Rate × Time) / 100**

Where:

* **Principal** is the initial amount of money.
* **Rate** is the rate of interest per year.
* **Time** is the time period in years.

## Features

* Accepts principal amount as user input.
* Accepts rate of interest as user input.
* Accepts time period as user input.
* Calculates simple interest using the standard formula.
* Displays the calculated simple interest.

## Technologies Used

* Bash
* Git
* GitHub

## Usage

Run the `simple-interest.sh` Bash script and enter the principal amount, rate of interest, and time period when prompted.

This project demonstrates basic Git and GitHub workflows while implementing a simple command-line calculator using Bash.
